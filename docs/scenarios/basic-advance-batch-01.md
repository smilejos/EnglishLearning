## 範圍與選詞方式

- 本批使用字庫分組 `basic` 與 `advance` 的聯集（OR），不加入 `expert` 或未分類詞。
- 已比對 [來源字庫](../../source/vocabulary-database.json) 的實際詞形、GUID、分組與詞性；未查詢或寫入正式資料庫，正式資料的一致性仍需日後確認。
- 候選池共 1,967 詞條：basic 1,193、advance 774；本批不是這 1,967 詞條的完整覆蓋計畫。
- 四十個情境各有八個目標詞（符合每圖六到十個的方向），每場景都包含名詞、動詞與形容詞；同一單字可出現在不同情境。
- `teachingPos` 與「本次詞義」只限定該情境的教學用法，不改動字庫的既有分級或多義資料；分組符合不等於所有詞義已經過獨立難度評定。
- 「畫面辨識方式」是生圖與後續審閱的要求，不代表圖片已成功呈現；尚未進行實際圖片品質或標籤位置驗收。
- 風格、模型、尺寸、文字燒入圖片或網頁疊加標籤等設定，留待圖片流程討論；本批不固定這些尚未確認的選項。
- [結構化 JSON](basic-advance-batch-01.json) 保存相同情境與字庫關聯，供後續規劃使用；不是目前 API 或 UI 已支援的匯入格式。
- 圖片互動、英文故事朗讀、繁中翻譯文字及既有字庫卡的後續討論，見 [情境學習需求與故事範例](scenario-learning-requirements.md)；目前只為 01 午後客廳準備故事範例。

### 01. 午後客廳

午後客廳中央放一張沙發，左側電視與右側檯燈留出間隔。一名孩子靠坐看書，另一名孩子閉眼休息；前方桌子與單椅清楚露出。

| 目標詞 | 分組 | 本次詞性 | 本次詞義 | 畫面辨識方式 |
| --- | --- | --- | --- | --- |
| sofa | basic | 名詞 | 沙發 | 中央完整呈現沙發的座位、椅背與扶手。 |
| television | basic | 名詞 | 電視機 | 左側牆前放一台有底座的電視，螢幕不顯示文字。 |
| lamp | basic | 名詞 | 檯燈 | 右側小桌上放一盞有燈罩與底座的檯燈。 |
| chair | basic | 名詞 | 椅子 | 前景右側放獨立單椅，椅腳與椅背清楚可見。 |
| table | basic | 名詞 | 桌子 | 前景中央放桌子，桌面與桌腳不被遮住。 |
| read | basic | 動詞 | 閱讀 | 孩子手持攤開的書，視線朝向書頁。 |
| sleep | basic | 動詞 | 睡覺 | 另一名孩子靠著沙發閉眼，放鬆雙手。 |
| comfortable | basic | 形容詞 | 舒適的 | 看書孩子靠坐在厚座墊上，肩膀與雙腿放鬆，神情自在。 |

審閱重點：

- comfortable 需藉姿勢與神情推知，不能像家具一樣直接辨識；先保留作審圖項目。
- cushion 與 rug 屬 expert，未列入本次目標詞；不在圖中標註。

### 02. 廚房準備早餐

明亮廚房中，一名大人用平底鍋煎蛋，孩子在旁切麵包。桌上放牛奶與兩個透明杯，讓杯中飲品的多少有明顯對比。

| 目標詞 | 分組 | 本次詞性 | 本次詞義 | 畫面辨識方式 |
| --- | --- | --- | --- | --- |
| kitchen | basic | 名詞 | 廚房 | 背景保留爐台、水槽與工作檯，呈現完整廚房空間。 |
| bread | basic | 名詞 | 麵包 | 前景砧板放一條麵包與切好的厚片。 |
| egg | basic | 名詞 | 雞蛋 | 桌前放完整帶殼雞蛋，旁邊另有破開的蛋殼。 |
| milk | basic | 名詞 | 牛奶 | 透明壺中裝白色牛奶，壺旁放同色飲品的杯子。 |
| cook | basic | 動詞 | 烹調 | 大人握鍋鏟，正在爐台平底鍋中煎蛋。 |
| cut | basic | 動詞 | 切 | 孩子在大人陪同下以餐刀切麵包，刀刃接觸麵包。 |
| hot | basic | 形容詞 | 熱的 | 爐台上剛煎好的早餐有少量上升蒸氣，hot 指向熱食，不要求人物先靠近再縮手。 |
| full | basic | 形容詞 | 滿的 | 前景杯子裝牛奶至接近杯口，旁邊空杯提供對比。 |

審閱重點：

- hot 以食物上的蒸氣提示溫度，不能用紅色代替熱；蒸氣只能作線索，仍需詞義輔助。
- full 本次教容器裝滿，不教吃飽；pour 屬 expert，未選。

### 03. 家庭一起用餐

一家人在餐桌前吃晚餐，飯碗與餐具分開擺放，彼此不遮擋。一人將一盤菜推向另一人分享，另兩人分別呈現準備開吃與吃飽後的姿勢。

| 目標詞 | 分組 | 本次詞性 | 本次詞義 | 畫面辨識方式 |
| --- | --- | --- | --- | --- |
| plate | basic | 名詞 | 盤子 | 桌前放白色扁平圓盤，盤沿完整可見。 |
| fork | basic | 名詞 | 叉子 | 盤子左側放四齒叉子，與湯匙隔開。 |
| spoon | basic | 名詞 | 湯匙 | 盤子右側放有圓凹匙面的湯匙。 |
| rice | basic | 名詞 | 米飯 | 中央飯碗盛白飯，清楚畫出幾粒米的形狀。 |
| eat | basic | 動詞 | 吃 | 一位家人把叉上的食物送到張開的嘴邊。 |
| share | basic | 動詞 | 分享 | 另一位家人把盛菜的盤子推向同桌的人，對方伸手接。 |
| hungry | basic | 形容詞 | 飢餓的 | 還沒開始吃的孩子一手摸肚子、一手伸向食物。 |
| full | basic | 形容詞 | 飽的 | 已吃完的家人面前有空盤，摸著肚子並擺手婉拒加菜。 |

審閱重點：

- hungry 與 full 是生理狀態，需姿勢與餐盤線索，仍可能與想吃、不想吃混淆。
- plate 只採餐盤詞義，排除來源混入的車牌與機芯說明。

### 04. 整理臥室

臥室中央露出床與枕頭，右側打開衣櫥與一格抽屜。孩子把玩具放進抽屜，另一人擦拭桌面；髒衣服堆與整理過的區域形成對比。

| 目標詞 | 分組 | 本次詞性 | 本次詞義 | 畫面辨識方式 |
| --- | --- | --- | --- | --- |
| bed | basic | 名詞 | 床 | 中央完整呈現床架與床面。 |
| pillow | advance | 名詞 | 枕頭 | 床頭獨立放一顆枕頭，不被棉被遮住。 |
| drawer | basic | 名詞 | 抽屜 | 右側矮櫃最上方抽屜拉開，抽屜盒與把手可見。 |
| closet | advance | 名詞 | 衣櫥 | 後方衣櫥打開，衣架與吊掛衣物可見。 |
| put | basic | 動詞 | 放 | 孩子雙手正把玩具放進拉開的抽屜。 |
| clean | basic | 動詞 | 打掃 | 另一人握布擦桌面，擦拭區域旁保留少量灰塵。 |
| tidy | basic | 形容詞 | 整潔的 | 左側已整理區域的物品整齊排在架上，地板無散落物。 |
| dirty | basic | 形容詞 | 髒的 | 右側待洗衣物上有明顯泥漬，與乾淨床面隔開。 |

審閱重點：

- tidy 本次取形容詞、clean 取動詞；避免兩個標籤都指同一處。
- fold 屬 expert，改以 put 呈現整理動作。

### 05. 洗衣與曬衣

洗衣區前景放洗衣籃與肥皂，一人清洗衣服，另一人把襯衫掛上曬衣繩。左側滴水的衣服與右側已乾衣物分區，襪子掛在容易辨認的位置。

| 目標詞 | 分組 | 本次詞性 | 本次詞義 | 畫面辨識方式 |
| --- | --- | --- | --- | --- |
| shirt | basic | 名詞 | 襯衫 | 中央衣繩掛一件有衣領、鈕扣與長袖的襯衫。 |
| sock | basic | 名詞 | 襪子 | 衣繩前端掛一隻清楚有腳跟與腳尖形狀的襪子。 |
| basket | basic | 名詞 | 籃子 | 前景放開口洗衣籃，籃體不被衣服完全蓋住。 |
| soap | advance | 名詞 | 肥皂 | 洗衣盆旁放一塊長方形肥皂，表面有泡沫。 |
| wash | basic | 動詞 | 清洗 | 人物把衣服放在水盆中搓洗，手部與泡沫可見。 |
| hang | basic | 動詞 | 懸掛 | 另一人正用衣夾把襯衫上緣固定到衣繩。 |
| wet | basic | 形容詞 | 濕的 | 左側衣物顏色較深且向下滴水。 |
| dry | basic | 形容詞 | 乾的 | 右側乾衣物沒有水滴，已整理好等待收入籃中。 |

- dry 缺乏直接可見性，需與滴水的 wet 衣物成對比較。
- basket 只採籃子，不採來源混入的咖啡濾杯詞義。

| pencil | basic | 名詞 | 鉛筆 | 筆記本旁放長鉛筆，削尖筆頭清楚可見。 |
| group | basic | 名詞 | 團體 | 左側三名孩子圍坐一桌形成一個小組。 |

圖書館中央有高書架與獨立借書櫃檯。一名孩子沿書架找書，另一名孩子從館員手中接取借出的書；前景第三名孩子吃力抱著一疊厚書，旁邊保留查詢電腦。

| --- | --- | --- | --- | --- |

| computer | basic | 名詞 | 電腦 | 查詢桌上有螢幕、鍵盤與滑鼠。 |
| borrow | basic | 動詞 | 借入 | 孩子在借書櫃檯雙手接過館員交出的書，呈現借閱交接。 |
