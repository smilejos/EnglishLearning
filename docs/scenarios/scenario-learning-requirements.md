# 情境學習：圖片、故事與單字卡需求

更新日期：2026-10-09。狀態：十五詞客廳試點的 migration、匯入器、API 與正式 App 情境頁已實作，底圖目視通過，十五組座標、Serena 旁白及 advance 27 段補音已備妥。目前只在 `_test` 作 [本機 QA](web-preview.md)，座標已通過桌面／手機 QA，旁白仍待使用者試聽；正式情境 migration、匯入及字庫補音 metadata 尚未寫入，未部署或發布。

## 已確認的方向

- 以單一使用者的英文學習平台為前提，保留既有驗證與角色權限。
- 第一批選詞使用 `level.list` 的 `basic`＋`advance` 聯集，不自動加入 expert 或未分類詞。已整理 [四十個八詞情境草稿](basic-advance-batch-01.md)，涵蓋名詞、動詞與形容詞；比較圖片後，使用者已選擇後續每圖十五詞，先做 [午後客廳一個完整試點](packages/living-room-15-v1/README.md)，再擴充其餘場景。
- 使用者認同互動圖片、顯示／隱藏英文標籤、看圖學習、看圖回想及聽音找圖的方向；看圖學習／回想已實作；聽音找圖的細節與實作順序留待後續。
- 每個情境增加一段描述圖片的英文情境故事，適合小朋友聆聽；故事和圖片必須描述相同人物、物件與動作。
- 故事採 **英文朗讀＋可展開的繁體中文翻譯文字**。本次不規劃中文故事朗讀。
- 圖片中的每個目標詞都能叫出既有字庫資料，查看單字、本次詞義、既有解釋、中英例句，並單獨播放已有的單字、英文解釋及英文例句音檔。
- 圖片和故事內的同一目標詞，應連到相同字庫詞條；情境內容不取代字庫原有資料。

## 建議的學習頁呈現

以下保留確認需求及目前正式 App 行為；聽音找圖、練習紀錄及逐句時間資訊留待後續。

1. **情境主圖**：保留完整場景，提供目標詞互動區域與標籤開關；名詞指向物件，動詞指向動作，形容詞指向可辨認的情境線索。
2. **聽故事**：使用者已指定由「放大圖片」旁的按鈕開啟故事與旁白 Modal，不常駐顯示故事。正式旁白提供明確的播放／暫停、重播與播放速度控制，不自動播放；音檔是整段英文，與單字、例句音檔分開。Serena 旁白已生成 31.896 秒，仍待使用者試聽。
3. **故事文字**：在故事 Modal 顯示英文段落，繁中翻譯預設收合。故事中可對應字庫的單字都能點選，十五個目標詞另作醒目標示；查詞切換同一 Modal 的內容，提供回到故事，不疊兩層。
4. **單字卡**：使用者已指定點字才開啟浮在圖片上方的 Modal，避免反覆捲動頁面。先呈現原形單字與這張圖的教學詞義，再提供既有字庫定義、解釋與中英例句；區分故事句與字庫既有例句。支援關閉按鈕、Escape、背景點擊、焦點回復及內部捲動。
5. **單字入口**：使用者已取消圖下單字列，改由圖片標籤或故事點字開卡。手機先放大圖片再點圖上標籤，也可由故事查字。

### 播放與練習建議

- 故事、單字、英文解釋及例句使用相同音源仲裁；開始播放另一音檔時，暫停前一個音源。
- 單純開啟單字卡不自動播放。若使用者播放單字或例句，故事暫停並保留位置，由使用者按「繼續聽故事」恢復，避免故事與單字重疊或突然自動續播。
- 切換情境或離頁時停止播放；缺音顯示「待準備」，播放失敗提供重試，不以讀取或點字觸發生成。
- 看圖學習可以同時顯示標籤與故事。看圖回想、聽音找圖的作答階段，應一起隱藏英文故事、翻譯與其他答案入口，避免隱藏圖上標籤卻仍直接露出答案。
- 可以先聽故事、再進入回想；「故事文字可隱藏」與「看圖回想」的切換不清除故事內容。
- 名詞可逐步做位置判斷；動詞、形容詞可能有多種合理解讀，先以揭曉、自行核對為主。收藏、熟悉與成績儲存不是本輪新增的確認事項，不因點選或播放自動收藏。

## 故事內容建議

- 先以短段落試作；客廳十五詞草稿為八個短句、七十五個英文單字。旁白已確認沿用本機 Qwen3-TTS／Serena；句數、長度與速度仍可在實際聆聽後調整，原八詞故事保留作比較。
- 讓十五個目標詞自然出現在故事中，都要找到明確對應，可使用合理的文法屈折形式。
- 盡量用 basic／advance 的簡單支援詞與句型；目標詞的分級是硬性邊界，故事支援詞的完整分級篩選規則仍待決定。客廳試點的目標與支援詞全部比對 basic／advance；下方保留的八詞範例全部英文字形對應的原詞均屬 basic。
- 故事可以營造場景氣氛，但不要要求圖片同時呈現互相矛盾的動作，或加入畫面沒有的重要情節。
- 名詞、動詞與形容詞採本次指定詞義；故事英文、繁中翻譯、圖片要求與單字卡的情境詞義需一致。
- 故事中的 `reads`、`sleeps` 等顯示字形，明確保存對應 `read`、`sleep` 的字庫 GUID；其他可點字也保存同樣關聯。單字卡展示原形，播放原形音檔，不把原形錄音當成屈折字形的錄音。
- 故事文字、翻譯及圖片內容確認後再安排產音；文字修改後要標示原故事音檔待更新，不繼續把舊音檔當成新版旁白。

## 沿用現有字庫的方式與缺口

現況依程式與 [字庫需求現況](../wordbank-practice-requirements.md)，不以本文件代表新功能已上線。

| 項目 | 現有能力 | 情境功能需要補上 |
| --- | --- | --- |
| 詞條關聯 | 第一批 JSON 已保存每詞的 GUID、詞性與分組 | 情境與故事字形沿用同一 GUID，不用隨機抽詞找答案 |
| 指定詞條讀取 | `GET /wordbank/entries/:guid` 已實作，提供有效音檔 metadata | 按情境指定 GUID 讀取，不隨機抽詞 |
| 單字內容 | 正式情境 `ScenarioWordCard` 已沿用中文定義、英文解釋、中英例句及音訊 | 正式字庫補音 metadata 尚待匯入 |
| 文章查詞彈窗 | 讀取文章單字及來源解釋，依賴文章與段落 | 可沿用互動與焦點處理經驗；情境的資料入口接字庫，不虛構文章來源 |
| 音源仲裁 | 故事及單字播放器已接 `audioBus`，保留故事暫停位置 | 待使用者實際播放驗收 |
| 字庫音檔 | basic 共 8,892 段；客廳 advance 三詞共 27 段已生成成功 | 本輪 advance metadata 尚未匯入正式庫，其他 advance 未整批產音 |
| 情境故事 | 故事、繁中翻譯、詞形 GUID、旁白及 revision 正式資料流程已實作 | `_test` QA 已完成；旁白使用者試聽及正式寫入／發布待完成 |

基本字庫的音訊準備紀錄不等於所有部署及實體檔案已在本輪重新核對。故事旁白是新音檔，不由既有單字或例句錄音拼接而成。文字範例階段沒有呼叫真實生成 API 或寫入正式資料庫；其後使用者已授權內建生圖工具生成 [五張效果預覽](../../output/imagegen/scenario-preview-2026-10-09-v1/README.md) 與 [客廳十五詞版](../../output/imagegen/living-room-15words-2026-10-09-v1/README.md)。本輪已執行本機 Qwen3-TTS 產出完整故事及客廳 advance 27 段補音；生成成功不代表聽覺驗收通過。正式情境介面已實作，尚未寫入正式資料庫或部署。

## 原八詞故事範例（保留比較）

這是早期討論長度、難度與點字方式的範例；後續客廳試點改採上方十五詞故事。其餘三十九個情境尚未追加英文故事。

### 英文段落

It is a quiet afternoon at home. A child sits on the **sofa** and **reads** a book. The child looks **comfortable**. Another child **sleeps** on the sofa. A **lamp** is on the right. A **table** and a **chair** are in front of the sofa. The **television** is on the left.

### 繁中翻譯

這是家中一個安靜的午後。一個孩子坐在沙發上讀書，看起來很舒服。另一個孩子在沙發上睡覺。檯燈在右邊，沙發前方有一張桌子和一張椅子，電視在左邊。

### 單字關聯

| 故事字形 | 打開的字庫詞條 | 說明 |
| --- | --- | --- |
| sofa | sofa | 故事出現三次，都打開同一張單字卡 |
| reads | read | 卡片顯示原形 read，提供原形單字錄音 |
| comfortable | comfortable | 本次教「舒適的」，搭配孩子放鬆坐姿 |
| sleeps | sleep | 卡片顯示原形 sleep，提供原形單字錄音 |
| lamp | lamp | 指向圖片中的檯燈 |
| table | table | 指向場景中沙發前方的桌子 |
| chair | chair | 指向圖片中的椅子 |
| television | television | 與圖片左側電視位置一致 |

[範例 JSON](story-sample-01.json) 保存逐句中英文字，以及全部五十個英文單字出現位置的字庫 GUID；`wordLinks` 區分目標與支援詞，`targetLinks` 另列八個目標詞的十個出現位置。字形範圍採各句字串的 0-based、起點包含／終點不包含字元索引；不是音訊時間戳。故事音檔狀態為未生成，這份 JSON 是內容規劃範例，不是現有 API 的匯入契約。
