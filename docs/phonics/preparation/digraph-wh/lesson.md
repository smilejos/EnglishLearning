# 子音字形 wh教材（digraph-wh）

2026-11-02，自編第一版；參照照片的教學範圍，依目前平台的先備與四階段重編，未抄用手寫答案。

## 課程設定

- 順序：五長短母音 → 第3章子音連綴 → sh → ch → 無聲th → 有聲th → wh → ph → tch／ch比較。
- 目標聲音：/w/，採美式示範；拼法：wh。
- 學習目標：採美式常見/w/，學習wh的拼字與整詞讀音。
- 教材來源：`screenshots/IMG_3294.HEIC`（p136）、`IMG_3295.HEIC`（p137）、`IMG_3296.HEIC`（頁碼未入鏡）；範圍參照原書，詞表、題目及短句為本批自編。
- 數量：7個實際韻尾字族，7個去重目標詞；3示範、8題（4聽音選字／4聽音拼字）、2短句。
- 製作範圍：前台教材接入的內容備料；實際接入、音訊生成、正式字庫回補、部署與人工品質驗收分開記錄。
- 共用字庫：逐詞GUID見下表，沿用既有詞條；本文件不代表已寫入正式庫。
- 先備：已學五長短母音、基本單字母子音及第3章雙子音連綴。
- 先備：同一字形可含多個字母；拼字作答塊與音素數量分開看。
- 先備：已教ee/ea、i_e/a_e；wh不提供不同於/w/的新口型，重點是字形。
- 份量理由：只收先備可承接的常用詞，不為配額加入未教母音、多音節或不穩定口音變體。

## 一、認識聲音

聽 when、wheel、white 的完整單字，留意 /w/；先看本課目標字形，再完整逐音拼合。

本課採美式常見的wh=/w/，h不另讀；部分口音保留/ʍ/，不當作發音錯誤。who不讀/w/，不收入本課。

播放完整單字，留意其中的目標聲音。沒有合格孤立音素錄音，不把音素文字或TTS字母名稱當成逐音音訊。

## 四、讀個短句

### The white whale is big.

這隻白鯨很大。

重點詞：white、whale；整句音訊：`digraph-wh/sentence-1`。

先聽支援片語再讀整句；冠詞弱讀、功能詞與特別提示不作本課新規則考核。

- `support-1-1`：**the white whale**；這個／那個；冠詞通常弱讀。
- `support-1-2`：**is big**；是／在；s在此讀/z/，先聽片語。
### When can I spin the wheel?

我什麼時候可以轉動這個輪子？

重點詞：when、wheel；整句音訊：`digraph-wh/sentence-2`。

先聽支援片語再讀整句；冠詞弱讀、功能詞與特別提示不作本課新規則考核。

- `support-2-1`：**can I spin**；我；固定大寫，讀/aɪ/。
- `support-2-2`：**the wheel**；這個／那個；冠詞通常弱讀。
