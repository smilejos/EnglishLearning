## 限制與接續

- reservation、leave、ask屬語境或服務動作；圖片提供錨點，精確意思仍需故事，不以圖示或姿勢宣稱獨立辨識成功。
- 茶與咖啡雖容器及顏色不同，洗髮精也有清楚獨立瓶身，但無文字外觀不能證明內容物；故事需明確指認。
- 表格以欄線呈現，沒有真實簽名或個人資料；手機訂房畫面沒有文字或日期。
- 圖片有29詞的可見或語境線索，但尚未配置網站互動標籤；手機放大與全標籤可讀性未驗收。
