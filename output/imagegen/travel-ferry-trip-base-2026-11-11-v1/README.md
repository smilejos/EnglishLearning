## 限制與接續

- ship是近景客輪局部，不宣稱可見完整全船；large可由主船與小船對比，但距離不同，仍需故事。
- 畫面有橙色救生圈，不是life jacket救生衣。life jacket與harbor僅為未採用的延伸候選，本圖沒有對應物件，不冒稱已涵蓋。
- ferry固定航線的用途需旅程語境。船已開航，畫面沒有碼頭登船，不混合boarding與sailing。
- 男士扶帽與孩子觀看海景清楚；既有故事是草案，正式定稿仍須與實圖逐句比對。
