## 字庫缺口與限制

- 29候選中27詞已有離線canonical GUID；business class與economy class兩個完整詞條尚缺，GUID維持null，不能宣稱正式詞卡或匯入套件已完成。缺詞規劃見[清單](../../../docs/scenarios/preparation/travel-scenarios-proposal/airplane-cabin-vocabulary-gaps.json)。
- 此圖採教學剖視，不代表特定真實機型或每家航空公司配置。商務／經濟艙靠座椅寬度、排距與隔簾暗示，仍需故事指認。
- 雲可透過窗戶看見；機翼與引擎以剖視外側呈現，不宣稱正常單一窗戶可以看見整組機翼／引擎，也不把它們畫在客艙內。
- 水、果汁內容物及舒適程度需語境說明；螢幕、耳機、雜誌、行李艙蓋與行李箱皆有獨立可見線索。
- 枕頭、毯子、安全帶及用餐器具是畫面支援物件，本輪沒有擅自擴成額外目標詞。
- 尚未完成兩缺詞補庫、完整token映射、互動標籤、旁白、音訊、手機UI及套件驗收。未連正式DB／volume、未產音、未匯入、未發布或部署。
