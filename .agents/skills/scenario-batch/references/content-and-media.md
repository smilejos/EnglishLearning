# 內容與素材

用於選詞、故事、圖片、座標與錄音。細節以 `shared/src/scenarios.ts`、`scripts/check-scenario-package.mjs` 與現行需求為準。

## 選詞：圖中線索 → 本次詞義／詞性 → 故事用法

字庫來源合格不代表適合這張圖。每詞保存 word、entryGuid、本次來源與實際分級、teachingPos、senseZh、可見線索、故事字形與定位，核對字庫原文。使用者指定詞依 [指定詞流程](user-vocabulary.md)，不受 basic／advance 限制；舊格式 list 的限制不靠偽標繞過。

| 詞類 | 採用依據 | 淘汰原因 |
| --- | --- | --- |
| 名詞 n | 可辨識物件；整體場景概念也有合理錨點 | 太小、遮住、圖中沒有，僅在想像故事中出現 |
| 形容詞 adj | 看得出的狀態、材質、大小或與活動有關的屬性 | 只能靠旁白猜；色彩與活動無關 |
| 動詞 v | 人物／物件有正在做的動作，能指向相應區域 | 靜態圖不支持；同一人物同時做矛盾動作 |

- 顏色不是一律禁用：預設候選詞中，整理臥室的 blue／white 缺乏活動意義可移除，科學混色的 blue／yellow 可是核心概念；使用者指定色詞時先調整活動／畫面支撐，不照此示例擅自刪詞。
- 多義詞依本次教學意義：plant、can、full 等要確認詞性與字庫意思。tall 要指高書架，不能因格式合法就指到人的身體。
- 教學詞義須由該 GUID 的字庫內容支撐；例如預設洗衣圖的晾衣繩若 line 詞條沒有繩義，就核對 rope 或其他適合詞條。若 line 是使用者明確指定的詞，走詞義核對／字庫補缺流程，不擅自改成 rope，也不能只填 senseZh 讓機械檢查通過。故事改詞後舊旁白要重新核對／標失效。
- 不臆測圖中書名、數字、膠水等細節。預設選詞重要物件缺失先換合理詞；使用者指定詞缺線索時，優先調整場景／拆場或換圖支撐該詞，不擅自換詞。
- 15 n／5 adj／最多 5 v 是目標，不是硬配額。預設候選詞依圖取捨；指定詞圖容納不了就拆場／調整圖片，保留原清單，記實際數量／理由。跨場可重複，每場內 word／GUID 必須唯一。

## 底圖

1. 現成圖實際檢視，不只讀舊 prompt 或 reviewed 標記。燒入英文答案的早期效果圖只供參考，不能當正式底圖。
2. 新圖沿用 `shared/src/scenarioStudio/` 現行十區塊 prompt，依實際結構組織場景、人物、物件、活動、構圖與風格；維持無燒字／無箭頭／無答案限制。
3. 留出標籤空間，主物件不被擋住，不為湊詞堆滿道具。推薦約 16:9，合格既有圖保留實際尺寸，不強制裁成 1600×900。
4. 生成後看圖逐詞核對，不假造人工審閱 gate。底圖適合時換候選詞／換標籤不需重產圖片，因文字與箭頭獨立疊在網站上；指定詞不能因生圖漏物件就擅自刪除。
5. 保存 prompt／工具、來源、SHA-256、尺寸與審閱。生成超時先找完成輸出，避免重複付費呼叫。

## 故事與映射

- 自然短句描述圖中同一活動，適合小朋友聽；全部目標詞出現，不寫成道具清單。兩個相連短段可用，不硬套固定句數、字數、秒數。
- 逐句 en／zh 語意一致，繁中自然，不新增圖中不存在的重要情節。預設分級模式的目標與支援詞 lemma 都在本場 basic／advance；指定詞模式不限此級別，但全部 lemma 仍須對應有效字庫詞條。
- `wordLinks` 涵蓋全部英文 token，順序、surface、start／end、原形 word、GUID、isTarget 正確。索引是句內 0-based、含起點不含終點的字元範圍，**不是音訊時間**。
- reads → read、books → book 等屈折形明確映射原詞；圖／故事同詞同 GUID，卡片播放原形音檔，不假稱為屈折形錄音。
- `textEn = sentences.map(s => s.en).join(" ")`，`textZh = sentences.map(s => s.zh).join("")`。不在全文另加換行破壞契約／hash。
- optional `story.paragraphBreakAfterSentenceIds` 指既有句 ID，不重複、不在末句之後；一個 break 形成兩段。按句子順序呈現，仍一個全文 MP3。舊版沒欄位不擅自補 `[]`。
- 套件與正式 tokenizer 對 apostrophe 可能有差異，優先避免縮寫、所有格；使用時 check 與 import dry-run 都需通過。

編寫備料 JSON 不等於匯入套件。以新版套件與 checker 為例核對 assets、source、generationPlan、未知欄位與缺件狀態，不把原始提案直接匯入。

## 定位

`interaction.label`／`interaction.object` 是圖片上的 0–1 比例座標；前者是文字位置，後者是箭頭落點。名詞指物件、動詞指動作、形容詞指可見狀態，概念詞錨點可放合理背景，避開臉與關鍵物件。

桌機展開所有標籤看遮擋、交叉、錯指，再在手機放大查核。以實際文字 bounding box 與可讀性判定碰撞，背景 padding 相碰不必然是文字重疊，不為微小邊框接觸反覆升版。調位後再核對受影響標籤。

已匯入版本不直接改座標，新 revision 可重用同圖同音。圖書館曾因 tall 指錯物件補版本，科學實驗曾只為標籤位置補版本；這是不可覆寫的實例，不是每場都要做三版。

## local TTS 與重用

- 本機 Qwen3-TTS／Serena，查既有 profile／endpoint。服務未運行先記阻擋，啟動服務要有授權，不由 helper 暗中啟動。
- 圖、詞、故事定稿並留 hash 綁定審閱後再產音。逐場處理缺件，重試前查 manifest、檔案與文字 hash。
- 全文英文 MP3，不拼字庫錄音，不按故事段落拆音，不產中文故事旁白。`textSha256` 綁定 `story.textEn`。
- 目標詞的單字、既有英文解釋、既有英文例句音檔核對 GUID／kind／文字 hash、metadata 與實體檔案，僅補缺少／失效項目，不重產整個 advance 字庫。
- 支援詞缺音如實顯示待準備，不擴大補音範圍。共用 manifest 正式匯入前切成本場 jobs。
- 故事文本變更使旁白失效；只改座標且文本不變可重用有效音。字庫文本變更也需重新核對，不能只用 GUID 判斷有效。
- 全部新音檔完整 ffmpeg 解碼，完整人工試聽與機械解碼分別記錄。檔案頭／hash／可播放不能代替發音和內容品質；沒聽就寫待驗收。
