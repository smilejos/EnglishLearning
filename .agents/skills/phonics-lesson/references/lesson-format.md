# 教材製作格式

用下列結構撰寫 `docs/phonics/preparation/<lesson-key>/lesson.md`。這份格式供製作與審閱，並非程式可直接匯入的 JSON schema；實際資料結構依當下實作轉換。所有教材數量都以實際清單計算。

本格式適用 a、e、i、o、u 全部長短母音教材，也供其他發音主題沿用四階段。下方短 a 詞表與短句僅示範填寫方式；新課須使用自己的目標讀音、拼法、字族、結構、詞義、練習及音訊／字庫對應。

## 課程設定

| 欄位 | 要填的內容 |
| --- | --- |
| 識別 | 小寫英數連字號 `lesson-key`、繁中標題、教材版本或修訂來源。 |
| 發音主題 | 核心聲音、對應字形、適用位置與重要例外；音標依本課示範口音核對。 |
| 學習目標 | 使用者完成後應能聽辨／讀出／拼出什麼。 |
| 先備內容 | 使用到的既有字音對應；新增規則與已教規則分開列。 |
| 教材依據 | 使用者指定來源、照片檔名／頁碼或自編；教材印刷內容與手寫答案分開判讀。 |
| 內容目錄 | 目標母音主題 → 本課拼法 → 字族；字族與每詞結構標籤分開保存。非母音主題如 sh 仍以目標音形為主題，按適合的韻尾組織，不虛構母音分類。 |
| 數量 | 各字族列適合的常用詞與實際數量，不硬湊 10／20 或三十詞；課程總詞數依識別去重。練習每課預設 8 題、短句每課預設 2 句，不自動按字族數倍增。 |
| 製作範圍 | 討論備料／製作接入／既有課修訂；音訊及正式操作的實際授權。 |
| 共用字庫 | 每詞既有或待新增詞條 GUID、本課詞義、原形／屈折形關係、重用／待新增／已入庫狀態；補缺增量與 canonical 同步紀錄。 |

## 一、認識聲音

填：短標題、繁中教學說明、約三個示範詞、每詞要標示的實際字形位置、音訊類型與播放目標。發音提示以容易操作且正確為準，不用中文近似音代替英語目標音。

如只有整字錄音，明寫「聽完整單字，留意其中的目標聲音」；不要安排一個其實播放字母名稱的「聽音素」按鈕。

## 二、看字拼讀

參考 [長短母音字族目錄](word-family-catalog.md)，先選定本課的母音、拼法與字族；目錄列的是候選，不要求一課全收。每個字族一張詞表，每列一詞，依先備規則與熟悉程度排序。第一個已規劃字族作進入時的預設，其他字族可自由切換。

字族表頭先記：主題、拼法、字族識別／顯示名稱、韻尾讀音、先備對應、教學順序與實際詞數。字族識別須含主題／拼法或讀音資訊，不能只用 `-ow` 或 `-ood` 作全站唯一 ID，以免不同讀音混在一起。

| 字族／組內順序 | 單字識別與本課詞義 | 實際讀音／韻尾 | 結構標籤 | 字形分組與目標位置 | 難度／先備理由 | 音訊識別與狀態 |
| --- | --- | --- | --- | --- | --- | --- |
| 如 -at，各族依實際數量排序 | 英文詞＋繁中詞義；共用詞用識別關聯，不複製計數 | 同字族須共同字尾拼法與共同韻尾讀音 | 如 CVC、CVCC、CCVC、CV、CCV、CCVCC | 明確分組與目標範圍，不能一律拆字母 | 交代使用了哪些已教對應 | 素材識別、備料狀態與獨立聽審狀態，詳後方音訊清單 |

結構標籤以本產品的音素約定、依示範口音判斷；字母與字形另記。新主題不可因只支援三種結構或配額不足就誤分類／混入別的目標音。若使用者指定詞量，列實際可用數與缺口，不偽造完成；未指定時以適合的常用詞為準。

字形標註可用 **0 起算、終點不包含** 的範圍，並保留原單字拼寫，方便接入程式：

- `cat`：`c [0,1)`、`a [1,2)`、`t [2,3)`；短母音 a 目標為 `[1,2)`。
- `clap`：`c [0,1)`、`l [1,2)`、`a [2,3)`、`p [3,4)`；母音不在第二個字母。
- `ship`：`sh [0,2)`、`i [2,3)`、`p [3,4)`；若主題是 sh，目標為整個 `[0,2)`。
- `cape`：`c [0,1)`、`a_e {[1,2), [3,4)}`、`p [2,3)`；同組包含不連續位置，畫面仍須保持 `cape` 的原始字母順序，不把 e 說成獨立發音。

標註以實際英文文字為準。使用不同切分法時寫明理由，詞的目標範圍與題目作答塊分開記錄。

以使用者提出的短母音 a 清單為例，可先做三個字族，共十四個詞，不需要補成二十或三十：

| 主題／拼法 | 字族 | 詞表與實際數量 |
| --- | --- | --- |
| 短 a／a | -at | cat、bat、hat、mat、sat；5 詞 |
| 短 a／a | -an | can、fan、man、pan、ran；5 詞 |
| 短 a／a | -ap | cap、map、nap、tap；4 詞 |

字族與結構是不同軸：

- `cap／map` 是 CVC、`clap／flap` 是 CCVC，都可屬 `-ap`。
- `camp` 是 CVCC、`stamp` 是 CCVCC，都可屬 `-amp`；是否收錄依先備規則決定。
- `day／see` 是 CV、`play／tree` 是 CCV，適合的長母音詞不因缺字尾子音而被排除。
- `ship` 的 sh 算一個 C；`rain` 的 ai、`cape` 的 a_e 各對應一個 V，字形位置仍分開保存。`cube /kjuːb/` 的 /j/ 是子音，結構為 CCVC；tube 則須核對示範口音。

字族可用來比較字首變化，但完整拼讀仍保留每個音素，不以 `c-at` 取代 `c／a／t`。全部播放只播目前字族的實際 N 詞，進度顯示當前詞／N；切主題、拼法、字族或改變詞表的結構篩選時，停止舊音訊／佇列，有詞時重設第一詞、不自動播放，無詞時清除選取、停用播放並顯示空狀態。若依要求分批，按鈕須清楚說明播放本批或全字族。

## 三、動手練習

每題記：

- 題目 ID、題型、畫面指令、播放文字與音訊識別。
- 正解、選項或作答塊、干擾設計理由。
- 確認後的中文詞義與簡短回饋。
- 是已示範詞或遷移詞、所屬主題／拼法／字族與結構標籤；遷移詞使用了哪些已教對應。

每課沿用八題預設，可交替四題聽音選字、四題拼字，並混合本課已學字族，例如 cat／can／cap 比較字尾；不自動每字族各八題。依主題可調整比例。選字題讓正解位置分散，不能出現兩個同音且都能成立的正解。拼字題的作答單位需明確：

- 用字母作答：例如 `ship` 需 `s、h、i、p` 四個塊。
- 用字形組合作答：例如 `sh、i、p` 三個塊，須先確認 renderer 支援，不能沿用字元長度判斷完成。
- 同字母重複：例如兩個 e 需兩個獨立塊 ID；不要用字母文字當唯一識別。

揭曉前不把中文答案、正解標記或答案名稱藏在播放按鈕的可及性標籤。選項本身自然包含正確候選詞，不等於洩漏哪個是正解。

## 四、讀個短句

每課預設兩句，不自動每字族各兩句。每句記英文、對應繁中、本課目標詞及來源字族、可點播詞、音訊識別，以及額外常用／例外詞。選部分已學詞自然造句，先簡短再增加已知結構，不為涵蓋全詞表而寫不自然的句子。

短母音 a 的既有例子：

1. `A cat sat.` → 一隻貓坐下了。
2. `A cat sat on a mat.` → 一隻貓坐在墊子上。

`cat、sat、mat` 是本課示範詞；`A / a、on` 另列支援詞。冠詞 a 在句中常弱讀，不能從拼寫相同推論它與 cat 的 a 同音。支援詞若尚未學過，先提供讀音／詞義示範，不把未教規則當本課解碼考核。新主題須重新檢查，不沿用不相干的提示或插畫。

## 音訊清單與審閱紀錄

音訊清單涵蓋所有實際播放用途：示範詞、練習題、可點播詞與短句。依 Skill 的「既有音檔優先、Qwen3-TTS 補缺」原則，先盤點本課需要的素材；同一錄音供多個階段或題目使用時，以素材識別關聯並去重計數。

| 欄位 | 紀錄內容 |
| --- | --- |
| 播放需求 | 素材識別、整字／整句／孤立音素／拼合類型、完整文字、使用階段／題目及本課目標讀音。 |
| 來源與對應 | 字庫／文章／教材來源、詞條 GUID／素材 GUID（若有）、原檔路徑或播放 URL；離線複製另記目的地。新生成才標為新生成。 |
| 回補字庫 | 新補整詞音的 entry／asset GUID、服務檔案路徑、metadata 待匯入／已匯入與第二功能讀取驗證；例句用子 GUID，音素等課程專用資產另記。 |
| 相容性 | 文字 hash、詞義與讀音／口音、語言、原模型／聲線／指令等設定；不同設定仍適用的理由或不採用原因。 |
| 備料狀態 | 每項去重需求以未盤點、已確認重用、已新生成或待生成擇一；查明無可用素材才標待生成。失效／不適用的來源候選與缺件或排除理由另記；字庫有詞不等於已有有效錄音。 |
| 檔案驗證 | 實體檔是否存在、可解碼、SHA-256、時長；只有 DB metadata 或 URL 尚不代表驗證通過。 |
| 人工聽審 | 待聽審／已聽審及結果；另記目標音、額外音、字首／字尾、句子自然度與本課用法。檔案有效不自動算品質通過。 |

四種備料主狀態互斥，加總等於本課去重需求數；未盤點不要計為待新生成。同一需求的失效候選被替代後，只按最後主狀態計一次，排除候選數另列。備料狀態、來源與聽審各自記錄，例如「字庫重用／檔案有效／待人工聽審」可同時成立。完整單字不能代替孤立音素；新句子也不將整字錄音串接後當作自然整句。有效且適合本課的素材不重產，既有原檔不擅改、不刪除。查找介面與現有腳本的實際限制見 [程式與音訊路由](repo-integration.md)。

`review.md` 至少記：

- 主題、拼法、字族及逐詞結構／音形重點的核對結果；各族實際數量與課程去重詞數；指定詞量未足額的實際缺口及處理方案；替換詞及理由。
- 相容性缺口與本次實際修改，是否仍有未支援的字形／題型。
- 共用字庫新增／重用／補缺清單、穩定 GUID、增量路徑、canonical 同步及實際入庫 read-back；未入庫與已入庫分列，既有詞條／有效錄音保留結果。流程見 [回補共用字庫](wordbank-backfill.md)。
- 音訊需求去重數、四種互斥備料主狀態的實際數量、另列失效／不適用候選及理由、manifest 路徑、解碼／hash／人工試聽結果。排除的來源候選不另計成新增需求，現有庫總量與本課使用量分開列。
- 相關測試、桌機／手機目視與實際播放證據；未做就記未做。
- 可開啟的預覽入口，或純內容規劃的「未接入，沒有新課預覽」；製作、接入、聽審、發布、部署分別處於什麼狀態。

## 分類與排序的參考依據

- [Education Scotland：Phonic approaches](https://education.gov.scot/resources/learning-to-read-early-years-plr/developing-skills-for-reading/implementation-of-phonic-approaches/)：以 fish 的 f / i / sh 說明字母與音素並非一對一；本產品據此明確分開音素分類與字形標註。
- [DfE：Phonics screening check assessment framework](https://www.gov.uk/government/publications/assessment-framework-for-the-development-of-the-year-1-phonics-screening-check/assessment-framework-for-the-development-of-the-year-1-phonics-screening-check)：其中 CVC 等採拼寫結構的表格慣例，提醒製作時不可把外部標記直接視為本產品的音素分群。
- [DfE：SSP programmes，Note 1](https://www.gov.uk/government/publications/phonics-teaching-materials-core-criteria-and-self-assessment/validation-of-systematic-synthetic-phonics-programmes-supporting-documentation)：保留由左至右的個別音素拼合；字族在本產品作整理與比較用途，不取代完整拼讀。
- 字族目錄及其來源支持範圍見 [長短母音字族目錄](word-family-catalog.md)。詞數依本課內容安排，不把來源誤稱為固定數量要求。
