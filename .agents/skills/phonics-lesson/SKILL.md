# 自然發音教材製作

把一個明確的發音重點做成可聽、可拼讀、可練習的教材。對話、教學說明與製作紀錄使用繁體中文，單字與短句使用英文。沿用既有四階段介面與播放行為，依主題變更內容。

## 定位與範圍

- 以 Repo 根目錄為基準；先讀 `AGENTS.md`、`docs/codebase-architecture.md` 第 1–3 節與第 13 節，接著讀 `docs/phonics-prototype.md`。
- 檢查工作樹與既有教材。判斷本次是討論／備料、製作並接入、修訂或接續；只要求規劃時交付教材草案，不執行生成或改寫應用。
- 沿用已確認的主題、教材來源、指定詞與授權。缺少核心主題時才詢問；其餘可合理推定的設定先註明，不重問既有決定。
- 預設一課一個核心發音重點；生活主題可用來選詞，但仍須說清楚字形與聲音的教學目標。混合複習課另外列出要複習的規則。
- 一次製作多個主題時，先列課程順序與各課先備規則，再逐課完成相同四階段；不把尚未教過的後續規則當作前課的練習前提。
- 新課用獨立 `lesson-key`，保留既有短母音 a。教材補缺沿用第二功能「單字練習」的共用字庫，不另建一套 phonics 字庫；不自動擴充後台、DB 結構、學習紀錄或收藏。正式寫入、發布、部署與真實生成仍依當次授權。
- 接續短母音 a 字族版或需要已實作範例時，讀 [短母音 a 實作與接續紀錄](references/short-a-example.md)。其中詞數、素材數與測試數是該輪快照，不是其他課程的配額或可沿用的驗證結論。

## 四階段格式

以下是沿用的預設，使用者指定數量、詞表或練習方式時優先採用；發音不符或內容不足時說明原因，不為湊數納入錯誤示範。

| 階段 | 製作內容與保留的操作 |
| --- | --- |
| 認識聲音 | 用簡短繁中說明本課聲音與字形，預設約 3 個清楚示範詞，標出實際教學位置並可點播。音標與發音提示只在有助理解時提供。沒有合格音素錄音時，使用完整單字示範並說清楚。 |
| 看字拼讀 | 以**母音主題 → 拼法 → 字族**組織內容，進入課程先顯示教學順序的第一個字族；各字族依適合的常用詞列出實際數量，不硬湊 10／20 詞。呈現每詞的字形分組、目標位置、中文詞義與結構標籤。個別詞點選立即播放，保留整字播放、0.8 倍速與全部播放；全部播放只播目前字族的實際詞表，同步切字／選取／進度，字間沿用 650ms，可停止或改點單字。 |
| 動手練習 | 每課預設 8 題，混合聽音選字與聽音拼字，可混合本課已學字族比較，例如 cat／can／cap；不引入未教的字音規則。確認前可調整，確認後提供正解與簡短回饋；以第一次作答統計本輪結果，支援錯題重聽、只重練錯題與全部重練。 |
| 讀個短句 | 每課預設 2 句，選取已學字族中的部分目標詞自然造句，逐步增加少量難度；英文自然、中文對應，翻譯預設收合。可播整句與點重點詞播放，使用者自行朗讀核對，不把完成按鈕當作錄音或自動發音評分。 |

四階段可自由切換。練習維持本輪暫存；離開練習後重設，不新增跨次成績、麥克風／ASR 或自動收藏，除非使用者另有要求。

## 母音、拼法、字族與結構

- 選主題與字族時讀 [長短母音字族目錄](references/word-family-catalog.md) 的對應段落。它是有來源的常見候選表，不是窮盡詞庫、既定課程清單或已驗收素材；實際選詞仍核對先備規則、讀音與詞義。
- 主題是目標聲音，拼法是表示該聲音的字形，字族以共同字尾拼法與共同韻尾讀音整理。例如長 a 的拼法有 `a_e／ai／ay`，可再分 `-ake／-ain／-ail／-ay`。不同拼法不能為湊詞量不經教學就混入同課。
- 其他音形主題如 sh，仍以該目標音形為主題，再按適用拼法與韻尾字族整理，不為套目錄層級而虛構母音主題。
- **字族是每一小組的學習單位，數量用來控制份量，不作主要分類依據。** 短 a 可先用 `-at` 五詞、`-an` 五詞、`-ap` 四詞，共十四詞；不要求每字族或每種結構各十／二十詞，也不要求每課涵蓋目錄所有字族。使用者另指定詞量時優先，但不能用錯音、冷僻詞或大量屈折變形湊數。
- 字族內由熟悉常用詞開始，優先比較字首變化，再安排同課其他字族與混合練習。保留完整音素拼合，例如 `c／a／t`；不能只用 `c-at` 或記韻尾猜字取代逐音拼讀。
- CVC／CVCC／CCVC 是**單字結構標籤或輔助篩選**，不作固定三個主群組。依本產品約定按示範讀音的音素計算 C／V，另存字形分組；也允許 CV、CCV、CCVCC 等實際結構，不把不符合的詞硬塞進三類。
- 同字族可跨結構：`cap／map` 是 CVC，`clap／flap` 是 CCVC，皆可屬 `-ap`；`stamp` 可屬 `-amp`，標 CCVCC，依先備知識決定收錄。`day／see` 是 CV、`play／tree` 是 CCV，不能因沒有字尾子音就排除適合的長母音教材。
- `sh` 等多字母字形若對應一個子音，只算一個 C；`ai` 或不連續 `a_e` 可對應一個 V。長 u 的 `/juː/` 包含子音 `/j/`，不把整串當單一 V；口音可能改變實際讀音與結構，需逐詞核對。
- 以實際讀音排除異音例外，例如 give 不併入 five／dive、cow 不併入 snow／grow、one 不併入 bone／stone；長 u 的 `/juː/`、`/uː/` 與 oo 的 `/uː/`、`/ʊ/` 分別標清楚。`-ore`、`-all` 等不直接塞進五種長短母音表。
- 切換主題、拼法、字族或會改變詞表的結構篩選時，停止舊音訊與佇列；有詞時選取新詞表第一詞並重設進度，**不自動播放**，無詞時清除選取並停用播放。篩選不得讓適合的 CV／CCV 詞被預設 CVC 排除；全部播放的範圍與進度分母都依目前實際詞表。若另要求分批，按鈕明示播放本批或全字族。
- 第三、四階段仍按一課預設八題、兩句，不自動每字族各複製一套。題目記來源字族／拼法／結構；依課程計畫選出本課已學範圍混合練習。

## 選詞、切分與題目

1. 讀 [教材製作格式](references/lesson-format.md)，建立本課教學目標、先備規則、來源、拼法與字族清單、逐詞結構標註。詞義與讀音須符合本課用法。
2. 以需要處理的字音對應與拼合難度排序；可先同字族，再變換字首／字尾，最後加入已知的子音組合或較長詞。**字長不是唯一難度標準**；不為增加字長引入未說明的新母音規則。
3. 每詞明列字形分組與目標位置。例如 `ship` 是 `sh / i / p`，不可把 `sh` 當成兩個獨立發音；`a_e` 須表達不連續的字形關係。目標可能有多個字母、不同位置或多次出現，不用全域標色某個字母代替教材標註。
4. 認識聲音與拼讀詞應共享清楚的教學重點。可加入少量未示範的遷移練習詞，但它們須只運用已教的字音對應，並在製作表標記；不拿陌生規則當陷阱。
5. 選字題的答案須唯一，干擾詞具有可比較的差異。拼字題提供足夠字母／字形塊；有重複字母時使用獨立塊識別，答案長度依實際作答單位判定。
6. 短句優先使用本課詞與已知規則；只選部分目標詞自然造句，不硬塞全部字族或全詞表。必要的常用詞／例外詞另列並說明；尚未學過的支援詞先提供讀音／詞義示範，不把未教規則當本課解碼考核。例如句中冠詞 `a` 的弱讀不能當成短母音 `/æ/` 示範。

## 從草案到教材

在 `docs/phonics/preparation/<lesson-key>/` 保存 `lesson.md` 與 `review.md`；接續既有課時先定位原紀錄，不另起重複批次。`lesson.md` 沿用參考格式，`review.md` 記內容、素材、接入、驗證的實際狀態與待辦。這是製作紀錄，**不是已存在的匯入契約**。

1. **備料**：完成四階段文字、排序理由、切分、題目、短句、音訊清單與相容性缺口。只做規劃時到這裡交付。
2. **核對現行支援**：讀 [程式與音訊路由](references/repo-integration.md)。目前是短母音 a 原型，不能宣稱只替換詞表即可支援所有主題。接入屬本次要求時，做新課所需的最小適配，保留既有課程與功能；不順帶重寫通用教材平台。
3. **補詞與準備音訊**：先讀 [回補共用字庫](references/wordbank-backfill.md)，區分缺詞與缺音。缺詞補完整詞條；已有詞只補缺少的內容／錄音。依音訊原則盤點既有素材，只用本機 Qwen3-TTS 補缺少、失效或不適合本課且無合適替代的錄音；新補整詞音回存共用字庫，教材保留對應識別，不只留在課程目錄。沿用既有同一操作授權；只做規劃或沒有實際生成／匯入授權時交可審閱的增量與缺件清單。此次若只是在建立或修訂技能，不因此生成音訊或寫正式庫。
4. **接入與驗收**：檢查下列內容與操作，紀錄可證明的結果。未做的試聽、UI 或正式環境驗收明確保留待辦。

## 音訊原則

- **既有音檔優先，Qwen3-TTS 只補缺**：同一完整單字錄音可供示範、拼讀點播及聽力題共用，不因換課、換題或更換儲存位置就重產。先查既有字庫，再查適合的文章／例句及教材素材；可用素材不足時列出缺件與原因。查找方式及目前支援見 [程式與音訊路由](references/repo-integration.md)。
- **補缺回到第二功能共用字庫**：真正缺詞才新增詞條，已有詞沿用 GUID。可由現行字庫契約承接的新補整詞錄音，完成共用檔案落地、字庫音訊 metadata 與教材對應；來源 JSON 同步維護。已有合格錄音不覆寫；需保留原音的多讀音缺口另存課程資產並記錄限制。整句可作為合適的字庫例句及子錄音，音素／逐音拼合保留專用教材資產，不塞入單字欄。具體格式與工具見 [回補共用字庫](references/wordbank-backfill.md)。
- 重用前核對素材用途、完整文字／文字 hash、詞義與實際讀音、語言／示範口音、模型／聲線及檔案有效性；如 read 等同形異音字不能只按拼字配音。整句需文字與用法相符，不將多段單字音串接後當作自然整句錄音。不同模型／聲線不代表音檔必然失效，需記錄差異並確認本課品質與一致性；原有生成設定不可改寫成新設定。
- 新生成沿用當次指定的本機 Qwen3-TTS；未指定變更時沿用現有模型／Serena 設定。先確認實際服務與工具，不默默切換雲端。有效且適合本課的素材不為驗證而重產。
- 保存來源系統、詞條／素材 GUID（若有）、原路徑或播放 URL、文字 hash、檔案 SHA-256、時長、原生成設定與試聽狀態。正式整合優先引用穩定的共用素材識別／介面；離線預覽可複製並保留來源，不擅改或刪除原檔。規範不代表目前前台已接入即時字庫查音。
- 純內容規劃可先將音訊來源標為「未盤點」，不必為列播放需求掃描全部字庫；未盤點與已確認缺音分開計數，不把前者當成全部需要新生成。
- 字庫收詞不等於已有錄音，DB 有 metadata 也不保證實體檔存在。只盤點本課需要的素材，每項去重需求以未盤點、已確認重用、已新生成或待生成擇一計數；失效／不適用的來源候選與排除理由另記，不累加到需求總數。音訊來源、檔案有效性與人工聽審分開記錄。查不到／缺音時明示，不在學習頁開啟或播放時自動生成。
- 完整單字、孤立音素與逐音拼合是不同素材。TTS 念出字母名稱或額外母音時，不把它標成合格音素；沒有可用音素錄音不阻止完整單字版試作，但交付要說明範圍。
- 播放沿用 `audioBus`。停止、改播單字、換階段、換題、離頁或外部音源接手都取消正在播放與待播計時器；舊 promise／媒體事件不得啟動下一詞。播放失敗停止佇列並提供重試，不跳過錯誤繼續播。
- 檔案可解碼與 hash 相符不等於教學品質通過。人工聽審核對目標音、字首／字尾、額外音、整句自然度及詞句讀音是否適合本課；未完成就保留待聽審狀態。

## 驗收與交付

- **教材**：四階段齊全；主題 → 拼法 → 字族關係正確，字族及去重後的課程詞數與畫面說明一致；不以固定配額湊詞。逐詞韻尾讀音、結構、字形、目標位置、詞義與排序有依據，正解、干擾項、短句與翻譯一致，常用／例外詞另有說明。
- **共用字庫與媒體**：新增／補缺詞條的來源 JSON、正式詞條及 GUID 一致；新增整詞音的服務檔案與 metadata 已核對，既有有效音未被取代。前台所有可播放內容都有正確音檔映射；缺音明示，不在開頁時自動生成；分開記錄來源、檔案驗證、人工聽審及實際入庫狀態。未執行正式回補不可標為已可供第二功能使用。
- **程式**：文件驗證檢查格式、路徑與內容。改程式則依影響跑相關測試，涵蓋字族導覽、不同詞數／CV 等結構、空字族／空篩選、切換或篩選後重設且不自動播放、只播當前詞表的連播順序／同步顯示、單字改播、停止與字間取消、錯誤重試、題目隱藏答案、長詞／多字母字形及重複作答塊。無論異動類型，提交前仍依 `AGENTS.md` 確認完整測試與 typecheck 的實際結果。
- **畫面**：桌機與手機確認字族及結構篩選、實際詞數排列、最長詞／選項、多字母／不連續字形、鍵盤操作與播放狀態。工具不可用時明示缺少視覺驗收，不以 source 或假 Audio 測試代替實際目視／試聽。
- **交付**：提供主題／教學目標、四階段教材、詞表排序理由、音訊來源與缺件、預覽入口、已做驗證及未驗限制；區分內容備妥、程式接入、音訊就緒、人工品質通過與正式部署。純內容規劃提供文件路徑並註明「未接入，沒有新課預覽」，不另造預覽器湊交付欄位。依專案 Git 流程收尾，不把教材製作視為 push 或部署授權。
